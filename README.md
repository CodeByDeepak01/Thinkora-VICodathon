## 🚀 About ABTalks

ABTalks is a **60-day coding challenge platform built for college students**.

The idea is simple:

**Build every day → Prove your work → Share your progress → Build your portfolio.**

Instead of treating coding practice as something students do privately, ABTalks turns daily progress into visible proof through:

- GitHub commits
- LinkedIn posts
- Learning streaks
- Challenge progress
- Achievements
- Developer profiles
- Leaderboards
- Portfolio-ready projects

The goal is not just to complete 60 days.

The goal is to **become more consistent, build real projects, and make your progress visible.**

---

# 🎯 Problem

Many college students want to become better developers but struggle with:

- Inconsistent coding habits
- Procrastination
- Starting projects but not finishing them
- Lack of public proof of their skills
- Weak GitHub activity
- Difficulty presenting their learning journey to recruiters
- Losing motivation after a few days

Traditional learning platforms often focus on **content consumption**.

ABTalks focuses on **daily action and visible progress**.

---

# 💡 Our Solution

ABTalks provides a structured **60-day challenge** where students complete one focused coding task every day.

Each day follows a simple workflow:

```text

Build Something

Submit GitHub Proof
      ↓
Share on LinkedIn
      ↓
Maintain Streak

Earn Progress & Achievements

Build a Stronger Portfolio
